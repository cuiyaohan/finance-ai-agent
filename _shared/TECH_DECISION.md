# 技术决策（固化版 · 不许反复横跳）

> 固化日期：2026-10-16　下次复核：2027-01-16 或「接到第一个 Java 交付单」时，以先到者为准。

## 1. 双轨策略

| 轨道 | 用途 | 技术栈 | 能否一键发布链接 |
|---|---|---|---|
| **v0.1 验证体** | 验证客户要不要、做演示、做获客素材 | Python + FastAPI（或 Node + Express） | ✅ 能，用 WorkBuddy「发布为应用」 |
| **v1.0 交付体** | 私有化交付、建立壁垒、收定制费 | Java 17 + Spring Boot + Spring AI | ❌ 不能。发布沙箱无 JVM，只能用 GitHub + 录屏 + 截图对外 |

**判断口诀**：给客户「点开就能用」的 → 做 v0.1；给客户「装到内网」的 → 做 v1.0。

## 2. v1.0 主栈（已锁定）：Spring AI 官方 + 智谱 GLM

理由：零成本起步（GLM-4.5-Flash / GLM-4.7-Flash 有免费额度）、OpenAI 兼容协议、改动 base_url 即可换模型。

**已核实版本号（2026-10-16 查 Maven Central）**

| 组件 | 版本 | 说明 |
|---|---|---|
| Spring Boot | **4.1.1**（GA） | 由 spring-ai-starter-model-openai:2.0.1 的 pom 反查确认 |
| Spring AI BOM | **2.0.1**（GA） | 最新 GA；2.1.0-M1 为里程碑版，生产不用 |
| spring-ai-starter-model-openai | **2.0.1**（GA） | 智谱走 OpenAI 兼容协议，用这个 starter |
| JDK | **17**（本机已有 Temurin 17.0.20.1）或 21 | 不要用默认的 1.8 |

**回退方案**（若 Boot 4.x 与 Spring AI 2.x 组合报错）：Spring Boot **3.5.15** + Spring AI **1.1.8**（同为已核实 GA 组合）。

**备用分支 B（客户指定阿里云时才走）**：Spring AI Alibaba BOM **1.1.2.4-security-fix** + DashScope，需阿里云百炼 API Key（付费）。

## 3. 智谱接入参数（已核实）

- 端点：`https://open.bigmodel.cn/api/paas/v4`
- 免费模型：`glm-4.5-flash`、`glm-4.7-flash`（来源 freellm.net，更新于 2026-09-10；第三方来源，以智谱控制台为准）
- ⚠️ **免费档并发限制约 1 个并发请求**（同一来源）→ Demo 只做串行调用，不要并发批处理；批量场景要排队或换付费档。
- 模型名以控制台「模型列表」为准，别照抄网上旧名。
- ⚠️ 有资料称「首次调用需充值 1 元激活」（51CTO 博客，未核实）→ 若调用报余额不足，去控制台充值 1 元再试。

## 4. 三条不能碰的技术边界

1. **发布沙箱不支持 Java/Maven/Gradle**（无 JVM）——Java 项目永远不要指望「发布为应用」。
2. **发布沙箱不提供数据库**（MySQL/PG/Redis/Mongo 全无）——v0.1 只用 SQLite / JSON 文件 / 浏览器存储。
3. **闲鱼禁止第三方智能体/自动化程序操作账号**（闲鱼社区法律声明，2026-09-30 更新、2026-10-07 生效）——闲鱼的挂单、擦亮、回复**必须手工在 App 里做**，不要用任何自动化脚本。
