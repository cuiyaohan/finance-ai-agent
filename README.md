# 投研情报 Agent · 每日简报自动化

> 券商研究员每天在多个平台手工汇总公开资讯。这套系统把它变成一条流水线：**抓取 → 清洗 → 摘要打标 → 落盘简报**，每日 8:30 前自动出具，每条带来源与时间戳。

```
人工汇总  ≈ 2 小时 / 天     →     自动流水线  ≈ 3 分钟 / 天
8 名分析师各自复制粘贴            统一模板 · 全链路留痕 · 私有化部署
```

---

## 这是什么

一个能跑的投研情报 Agent。定时抓取公开财经信源，模型只负责打标与写摘要，**数字与抓取全部由确定性代码完成**。输出强制附免责声明，内置 54 词高危表扫描。

**技术栈**：Java 17 + Spring Boot 4.1.1 + Spring AI 2.0.1 + 智谱 GLM（OpenAI 兼容）· 另有 Python v0.1 快速验证版

## 真实产出长什么样

`docs/` 与各 `output/` 目录是真实运行产物，非示意。示例（2026-10-16 真实抓取，3 个信源 / 4 条资讯）：


## 合规护栏（金融场景的刚需）

| 护栏 | 实现方式 |
|---|---|
| 高危词扫描 | 54 词表（投资建议类/绝对化用语/站外导流/敏感品类），发布前一键自检 |
| 强制免责声明 | 每次输出末尾自动追加，不依赖人工记得加 |
| 数字对账 | 数字由代码计算，模型仅做文字解读，不参与金额运算 |
| 全链路留痕 | 每次调用写`trace.jsonl`，可审计 |

## 快速开始

```bash
git clone git@github.com:cuiyaohan/finance-ai-agent-demos.git && cd finance-ai-agent-demos
cp .env.example .env      # 填入智谱 API Key（.env 不进 Git）
```

**私有化交付版（Java）**
```bash
cd v1-invest-intel
mvn spring-boot:run -q                          # 启动，默认 8080
curl -X POST localhost:8080/run                 # 触发一次完整流程
curl "localhost:8080/chat?msg=这批资讯有无异常"  # 对话接口
cat output/brief_$(date +%Y%m%d).md             # 查看产出
```

**快速验证版（Python）**
```bash
cd v0-invest-intel
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m uvicorn app:app --host 127.0.0.0 --port 8000
# 浏览器打开 http://127.0.0.1:8000，点「生成今日简报」
```

**报表自动化 Demo**（数值由pandas 计算，模型只解读）
```bash
cd v0-report-automation
.venv/bin/python -m uvicorn app:app --host 127.0.0.1 --port 8001
```

## 两个 Demo 一览

| Demo | 输入 | 输出 | 单次耗时 | 单次成本 | 核心差异 |
|---|---|---|---|---|---|
| A 投研情报 | 3 个财经 RSS | 结构化情报简报（含标签、来源、免责声明） | 约 23 秒 | 约 0.0012 元 | 带合规护栏与打码 |
| B 报表自动化 | 1 份 CSV | 经营月报 + 异常清单 CSV | 约 7 秒 | 约 0.0005 元 | **数字由 pandas 算，模型只解读，且自动对账** |

> 模型选择实测结论：官方免费档 `glm-4.7-flash` 高峰期限流严重（429），曾让单次耗时涨到 210 秒，故默认用`glm-4.5-flash`。成本以智谱控制台为准。

## 已知局限（诚实说明）

- 免费模型档并发约 1，高峰期可能触发限流 → 已做规则摘录降级兜底
- 内部只读接口需客户方提供权限后方可接入
- 不提供买卖方向、收益类表述、具体金额运算

## 技术决策

- **双轨**：v0.1（Python+FastAPI）快速验证与获客；v1.0（Java 17+Spring Boot+Spring AI）私有化交付。详见 `_shared/TECH_DECISION.md`。
- **模型只做整理与行文**：数字、抓取、计算全由确定性代码完成，模型被系统提示词硬约束。
- **合规优先**：金融场景下「会不会踩红线」比「像不像智能体」重要，护栏是内置能力而非事后补丁。
