# 金融 + AI Agent 定制 · 两个可运行的垂直 Agent

> 把金融团队每天重复的信息汇总与报表撰写，变成自动跑的流水线。
> 共同的设计底线：**数字、抓取、计算全部由确定性代码完成，模型只负责摘要与行文。**

| Demo | 解决什么问题 | 输入 → 输出 | 技术栈 | 状态 |
|---|---|---|---|---|
| **A · 投研情报** | 研究员每天在多个平台手工汇总资讯，耗时且口径不一 | 3 个财经信源 → 结构化每日简报（含利好/中性/风险标签、来源、免责声明） | Java 17 + Spring Boot 4 + Spring AI | ✅ 每日定时实跑，真实产出见 [`v1-invest-intel/samples/`](v1-invest-intel/samples/) |
| **B · 报表自动化** | 财务月报里大量时间花在拉数、算环比、写三段话 | 1 份 CSV → 经营月报 + 波动异常清单 | Python + pandas | ✅ 自动对账，样例见 [`v0-report-automation/samples/`](v0-report-automation/samples/) |

两条流水线共用一套地基（[`_shared/`](_shared/)）：54 词高危表、强制免责声明、系统提示词约束、技术决策记录。

## 为什么敢让模型碰金融内容

金融场景里 AI 最大的风险不是「不够聪明」，是「一本正经地算错数、说错话」。所以下面这些护栏是**写死在代码里的**，不是提示词里求来的：

| 护栏 | 实现方式 |
|---|---|
| 数字不由模型算 | 抓取、去重、计算全部由确定性代码完成，模型仅做文字解读 |
| 高危词扫描 | 54 词表（投资建议类 / 绝对化用语 / 站外导流 / 敏感品类），发布前一键自检 |
| 强制免责声明 | 每次输出末尾自动追加，不依赖人工记得加 |
| 自动对账 | 报表 Demo 中，报告内每个数字均可回溯到计算结果，模型没编、没算错 |
| 全链路留痕 | 每次调用写 `trace.jsonl`，可审计 |

## 快速开始

```bash
git clone git@github.com:cuiyaohan/finance-ai-agent.git && cd finance-ai-agent
cp .env.example .env      # 填入智谱 API Key（.env 不进 Git）
```

**A · 投研情报 —— 私有化交付版（Java，数据不出域）**
```bash
cd v1-invest-intel
mvn spring-boot:run -q                          # 启动，默认 8080
curl -X POST localhost:8080/run                 # 触发一次完整流程
curl "localhost:8080/chat?msg=这批资讯有无异常"  # 对话接口
cat output/brief_$(date +%Y%m%d).md             # 查看产出
```

**A · 投研情报 —— 快速验证版（Python）**
```bash
cd v0-invest-intel
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m uvicorn app:app --host 127.0.0.1 --port 8000
# 浏览器打开 http://127.0.0.1:8000，点「生成今日简报」
```

**B · 报表自动化（Python）**
```bash
cd v0-report-automation
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m uvicorn app:app --host 127.0.0.1 --port 8001
# 上传 CSV → 自动算同比/环比/占比/异常 → 生成月报 + anomalies.csv
```

## 实测数据（2026-10-16，自带示例数据）

| Demo | 输入 | 输出 | 单次耗时 | 单次成本 | 核心差异 |
|---|---|---|---|---|---|
| A 投研情报 | 3 个财经信源 | 结构化情报简报 | 约 23 秒 | 约 0.0012 元 | 合规护栏 + 打标 + 降级兜底 |
| B 报表自动化 | 1 份 CSV | 经营月报 + 异常清单 CSV | 约 7 秒 | 约 0.0005 元 | **数字由 pandas 算，模型只解读，且自动对账** |

> 模型选择实测结论：官方免费档 `glm-4.7-flash` 高峰期限流严重（429），曾让单次耗时涨到 210 秒，故默认用 `glm-4.5-flash`。成本以智谱控制台为准。

## 已知局限（诚实说明）

- 免费模型档并发约 1，高峰期可能触发限流 → 已做规则摘录降级兜底
- 内部只读接口需客户方提供权限后方可接入
- 不提供买卖方向、收益类表述、具体金额运算

## 技术决策

- **双轨**：v0.1（Python + FastAPI）快速验证与获客；v1.0（Java 17 + Spring Boot + Spring AI）私有化交付。详见 [`_shared/TECH_DECISION.md`](_shared/TECH_DECISION.md)。
- **模型只做整理与行文**：数字、抓取、计算全由确定性代码完成，模型被系统提示词硬约束。
- **合规优先**：金融场景下「会不会踩红线」比「像不像智能体」重要，护栏是内置能力而非事后补丁。
