投研情报 Agent · 演示旁白稿

> 时长约 15 秒，对应剪辑后两段画面。
> 用macOS `say -v Tingting` 合成，无需真人配音。

---

## 旁白文案（最终版）

### 画面 1（0–4 秒）：简报成品

> 每天早上，这是一份自动生成的投研简报。四条资讯，每条都带来源和原文链接。

### 画面 2（4–15 秒）：运行结果

> 点一次接口，两分钟不到，全自动完成。
> 抓取三个信源，模型打标，高危词扫描零命中，末尾强制附免责声明。
> 代码和实测记录都在 GitHub 仓库里，欢迎直接审阅。

### 画面 1
> 这是一份自动生成的投研简报，四条资讯都带来源和链接。

## 字幕文案（硬字幕，与旁白同步）

| 时间 | 字幕 |
|---|---|
| 0–4s | 每天早上，这份投研简报自动生成 |
| 4–7s | 四条资讯，每条带来源与原文链接 |
| 7–11s | 一次调用，两分钟内完成抓取与打标 |
| 11–15s | 高危词零命中 · 强制附免责声明 · 代码开源可审 |

---

## 合规检查（重要）

旁白与字幕中已确认**不含**以下内容：
- 买卖方向、收益类表述
- 极限词（最 / 头一个 / 百分之百）
- 站外导流信息

**注**：字幕里的「零命中」指合规扫描结果为 0，不是极限词。

---

## 合成命令（已执行）

```bash
# 1. 生成中文语音
say -v Tingting -o /tmp/vout/旁白.aiff "每天早上，这是一份自动生成的投研简报。..."
say -v Tingting -o /tmp/vout/旁白2.aiff "点一次接口，两分钟不到，全自动完成。..."

# 2. 与视频合成（ffmpeg 来自 imageio-ffmpeg）
ffmpeg -i 剪辑版.mp4 -i 旁白.aiff -i 旁白2.aiff -filter_complex "[0:v][1:a]…[a1];[a1][2:a]concat=n=2:v=0:a=1[a]" -map 0:v -map "[a]" -c:v copy -c:a aac 输出.mp4
```

> 注：源录屏无音轨（纯画面），旁白为后配。
