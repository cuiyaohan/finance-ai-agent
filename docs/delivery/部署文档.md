# 部署文档 · v1-invest-intel（Java 私有化版）

> 目标：假设读者不懂代码，从「拿到代码」到「服务起来」，每一步都能在干净的内网环境执行。
> 提供 JDK 17 与 Docker 两条路径，任选其一。

## 〇、拿到的是什么

一个 Spring Boot 服务，功能：抓取公开信源 → 清洗去重 → AI 摘要打标 → 生成带免责声明的 Markdown 简报。
代码根目录：`v1-invest-intel/`。

## 一、准备工作（两条路径都要）

1. 准备一个模型接口 Key（本方案走 OpenAI 兼容协议，默认接智谱 GLM）；
2. 确认服务器能访问模型服务地址（内网不通时见「运维手册 · 换模型」）。

## 二、路径 A：JDK 17 直接运行

### A1. 安装 JDK 17
```bash
# 校验（必须显示 17 或 21）
java -version
```
> 若无 Java 17，请先安装 Eclipse Temurin 17（官网下载对应系统安装包，双击安装）。

### A2. 安装 Maven（若用源码构建）
```bash
mvn -version   # Java 需为 17
```

### A3. 构建
```bash
cd v1-invest-intel
mvn -DskipTests clean package
```
产物：`target/v1-invest-intel-1.0.0.jar`。

### A4. 启动
```bash
export SPRING_AI_OPENAI_API_KEY="你的Key"
export SPRING_AI_OPENAI_BASE_URL="https://open.bigmodel.cn/api/paas/v4"
export SPRING_AI_OPENAI_MODEL="glm-4.5-flash"
java -jar target/v1-invest-intel-1.0.0.jar
```
看到 `Started InvestIntelApplication` 即启动成功（端口 8080）。

### A5. 验证
```bash
curl "http://127.0.0.1:8080/chat?msg=你好"
```
返回内容非空，且末尾含「仅供参考，不构成投资建议」即通过。

## 三、路径 B：Docker 运行

### B1. 构建镜像
```bash
cd v1-invest-intel
docker build -t v1-invest-intel:1.0.0 .
```

### B2. 运行容器
```bash
docker run -d --name invest-intel -p 8080:8080 \
  -e SPRING_AI_OPENAI_API_KEY="你的Key" \
  -e SPRING_AI_OPENAI_BASE_URL="https://open.bigmodel.cn/api/paas/v4" \
  -e SPRING_AI_OPENAI_MODEL="glm-4.5-flash" \
  v1-invest-intel:1.0.0
```

### B3. 验证
```bash
curl "http://127.0.0.1:8080/health"
```

## 四、配置项一览

| 环境变量 | 含义 | 默认值 |
|----------|------|--------|
| SPRING_AI_OPENAI_API_KEY | 模型接口密钥（必填） | 无 |
| SPRING_AI_OPENAI_BASE_URL | 模型服务地址 | https://open.bigmodel.cn/api/paas/v4 |
| SPRING_AI_OPENAI_MODEL | 模型名 | glm-4.5-flash |
| SERVER_PORT | 服务端口 | 8080 |

> ⚠️ 密钥只通过环境变量注入，不要写进代码或提交到代码库。
