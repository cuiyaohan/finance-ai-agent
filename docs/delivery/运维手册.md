# 运维手册 · v1-invest-intel

> 日常启停、日志位置、常见故障处理、如何换模型/换信源。

## 一、日常启停

- 启动（jar）：`java -jar target/v1-invest-intel-1.0.0.jar`
- 启动（docker）：`docker start invest-intel`
- 停止（docker）：`docker stop invest-intel`
- 重启：`docker restart invest-intel`
- 后台常驻（Linux）：用 `nohup ... &` 或交给 systemd / 容器编排托管。

## 二、日志在哪

- 应用日志：控制台输出；如需落盘，用 `java -jar app.jar > app.log 2>&1 &`。
- 运行 trace：`logs/trace.jsonl`，每条一行 JSON，含时间、接口、耗时、是否含免责声明。
- 生成的简报：`output/brief_YYYYMMDD.md`。

## 三、接口清单

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /chat?msg= | 返回模型回复（末尾附免责声明） |
| POST | /run | 触发抓取→清洗→摘要→成简报 |
| GET | /latest | 返回最近一次生成的简报正文 |
| GET | /health | 健康检查 |

## 四、常见故障与处理

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 启动报 api-key 相关错误 | 未设置密钥环境变量 | 设置 SPRING_AI_OPENAI_API_KEY 后重启 |
| /chat 返回 400 模型调用失败 | 网络不通或密钥失效 | 检查服务器到模型地址的连通性与密钥 |
| 简报只有 3 条且带「示例数据」 | 信源抓取失败 | 检查服务器能否访问信源域名；确认后重试 |
| 端口被占用 | 8080 已被占用 | 设置 SERVER_PORT 换端口 |
| 返回内容为空 | 模型思考输出占满长度 | 改用 glm-4.5-flash，或调大输出长度 |

## 五、如何换模型 / 换信源

- 换模型：改环境变量 SPRING_AI_OPENAI_MODEL 后重启即可（如 glm-4.6）。
- 换模型服务商：改 SPRING_AI_OPENAI_BASE_URL 与密钥（仍走 OpenAI 兼容协议）。
- 换信源：编辑 `src/main/java/.../service/BriefService.java` 里的 SOURCES 列表，重新构建。
- 换系统提示词：编辑 `src/main/resources/system-prompt.txt`，重新构建。

## 六、升级与备份

- 升级：替换 jar 或镜像后重启；
- 备份：只需备份 `output/`（简报）与 `logs/`（trace），无数据库。
