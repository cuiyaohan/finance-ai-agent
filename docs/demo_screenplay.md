# 演示录屏分镜脚本（闲鱼 / 小红书 / GitHub 封面通用）

> 用途：照着录一段 60–90 秒的演示视频，证明「这不是 PPT，是真的能跑」。
> 工具：系统自带屏幕录制或 OBS；分辨率 1920×1080，帧率 30，全程静音录屏后配画外音。
> 红线：录屏只展示「输入→输出」，绝不露出 `.env`、密钥、浏览器地址栏中的 token。

---

## Demo A：投研情报 Agent（约 35 秒）

| 镜头 | 画面 | 画外音 | 时长 |
|---|---|---|---|
| A1 | 终端：`cd agent-demos/v0-invest-intel && uvicorn app:app --port 8000` | "这是一个投研情报 Agent，输入是多个财经 RSS 信源。" | 4s |
| A2 | 浏览器打开 `127.0.0.1:8000`，点「生成今日简报」 | "点一下，自动抓取、清洗、让大模型摘要打标。" | 6s |
| A3 | 进度等待约 16–31 秒（可加速播放） | "单次约 20 秒出一份简报。" | 慢放 8s / 加速 3s |
| A4 | 简报页面：今日要点 5 条 + 利好/中性/风险标签 | "自动打利好、中性、风险标签，附来源链接。" | 6s |
| A5 | 滚到文末：免责声明「仅供参考，不构成投资建议」 | "末尾强制附带免责声明，合规护栏是内置的。" | 5s |
| A6 | 终端：`curl /stats` 显示 Token、耗时、成本 0 元 | "每次运行都记成本，对客户讲「多少钱一次」很方便。" | 6s |

## 录制注意事项

1. **遮罩敏感区**：录制前把 `.env`、终端历史、浏览器已保存的密码窗口关掉；任何带 token 的命令行一律不录。
2. **加速说明**：Demo A 的真实等待约 20 秒，成片可加速到 3–5 秒，但需在画外音里说明「真实约 20 秒」。
3. **合规**：录屏旁白与字幕不得出现投资建议类、绝对化用语类、站外导流类高危词（完整词表见 `_shared/high_risk_words.txt`，发布前跑一遍 `bash check_compliance.sh`）。
4. **导出**：1080p MP4，H.264，单文件 ≤ 200MB，命名为 `demo-投研情报.mp4` / `demo-报表自动化.mp4`。
