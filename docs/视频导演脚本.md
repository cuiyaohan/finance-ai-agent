# 演示视频导演脚本 · 投研情报 Agent

> 用途：照着念 + 照着敲，10 分钟录完一条2–3 分钟成片。
> 目标观众：券商研究部 / 企业客户。核心目标是让人相信「这事能落地」，不是炫技。
> 成片标准：≤3 分钟、有真实数字、有边界说明、不吹牛。

---

## 录制规格

| 项 | 值 |
|---|---|
| 分辨率 | 1920×1080（或 2560×1440，字号调大） |
| 帧率 | 60fps（终端动画更顺） |
| 麦克风 | 就近收音，嘴离麦 15cm 以内 |
| 环境 | 关掉通知、关社交软件、关邮件弹窗；终端字号调到 14pt 以上 |

## 三种拍法（按你选的路径二选一）

### 拍法 A：HTML 终端回放页（推荐，省时）

1. 浏览器打开 `docs/demo_terminal.html`，按 `F11` 全屏。
2. 按 `空格` 或 `→` 逐页推进（共 6 段：问题 → 方案 → 实跑 → 产物 → 价值 → 边界）。
3. 系统录屏：`⇧⌘5` → 选「整个屏幕」→ 点录制。全程只推进 6 次，每次讲 20–30 秒。
4. 后期裁到 2–3 分钟。

**注意**：页面上「实跑」段的输出是**真实运行结果**（3 信源 / 4 条 / 1 条降级），不是伪造。

### 拍法 B：真机 Terminal 实跑（可信度最高）

| 镜次 | 时长 | 你要做的 | 口播台词 |
|---|---|---|---|
| 1 | 20s | 展示 README 开头与架构图 | 「研究员每天手工汇总公开资讯，8 个人口径还不一样。这套 Agent 把抓取、清洗、摘要、推送做成一条流水线。」 |
| 2 | 25s | `cd v1-invest-intel` → `mvn spring-boot:run -q`，展示启动日志 | 「Java 17 加 Spring Boot 加 Spring AI，私有化部署，数据不出内网。启动 3 秒。」 |
| 3 | 40s | 另开一个终端 `curl -X POST localhost:8080/run` | 「触发一次真实抓取。三个信源，去重过滤，模型打标，全程大概两分钟。」 |
| 4 | 30s | `cat output/brief_20261016.md` | 「产出是这么一份简报：每条带来源、带时间、带原文链接，末尾强制附免责声明。」 |
| 5 | 25s | `bash check_compliance.sh` | 「内置 54 词高危表，扫描零命中。这是金融场景的底线——只做信息整理，不碰买卖方向。」 |

## 旁白要点（贯穿全片）

必须说到的三件事：

1. **真实数字**：「人工 2 小时 → 自动 3 分钟」「8 名分析师」「3 个信源 / 4 条资讯」。
2. **合规边界**：「只做信息整理，不构成投资建议」——这句话要说出来，它是金融客户的决策依据。
3. **诚实局限**：「免费模型并发约 1，高峰会限流，已做降级兜底」——主动说局限反而加分。

---

## 禁止事项（踩线即封号/丢单）

- 不出现任何站外导流信息（社交账号、图形码、号码）。
- 不说「最」「头一个」「百分之百」等极限词。
- 不做买卖方向或收益表述。
- 不承诺「终身有效」类表述，不使用医疗类夸大词。
- 演示视频与闲鱼/小红书物料同属合规范围，录完我再跑一遍高危词自查。
