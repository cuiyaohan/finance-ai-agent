## 字幕样式

- 字号 42，白字黑描边
- 位置：底部 250px（避免遮挡画面内的能力标签）
- 逐词高亮：当前词显示为蓝色 `#60a5fa`
- 逐词渐入：180ms ease-out，translateY 0.22em → 0
